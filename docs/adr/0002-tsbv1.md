# ADR 0002 — `TSBV1`: one self-describing, pre-gzipped binary container per vocabulary

- **Status:** Accepted (2026-10-25). Stub written by WP00; WP02 (reader) and WP03 (writer) may extend the rationale.
- **Layout (FROZEN v1):** `packages/core/src/format/README.md` (verbatim copy of `docs/design/03-data-model-and-assets.md`
  §C.1); in-memory types in `packages/core/src/format/types.ts`.

## Context

Upstream vocabularies come in six formats (tiktoken rank files, SentencePiece protos, HF `tokenizer.json`, Grok-2 JSON,
the legacy Claude JSON) and two of them exceed the 25 MiB per-file limit of Cloudflare static assets. Edge compression
drops `Content-Length` (no exact progress) and saves only 2–3 % over gzip-9; `DecompressionStream('brotli')` is missing in
Chrome. The Worker needs byte-keyed lookups with small resident memory on 3 GB phones.

## Decision

- One little-endian section container per tokenizer: `META PCES TYPS PRIO|SCRF MRGS SPCL`, every section length-prefixed
  so readers can skip unknown tags; unknown `version` is rejected (03 §C.1, AD-10).
- Pre-gzipped at build (zopfli or zlib-9, deterministic), served as opaque `/tok/<id>/<sha12>.bin` with
  `Content-Type: application/octet-stream`, `nosniff` and `immutable` (06 §6).
- The loader sniffs the payload (`1F 8B` vs `TSBV`) and verifies `sha256` or `sha256Raw` accordingly (AD-37).
- Specials ship inside the asset in source order (`SPCL`, AD-12); Gemma 4 ships its exact merge table (`MRGS`, AD-6);
  scores are shipped, not derived (AD-7).

## Consequences

- A `.bin` is self-describing (`META` carries provenance), so tests and `tsbs-vocab inspect` need no registry.
- The converter refuses to write an asset that fails its golden fixture (AD-13), with the interim
  `skip-missing-engine` mode until both engines exist (AD-32).
- `.br` siblings can be added in v1.1 through the manifest `encoding` field without a protocol change.
